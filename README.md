# Buen Rollo Escapes

Direct-booking marketing site for Buen Rollo Escapes — boutique apartments
in Guatemala City and Antigua Guatemala, plus off-grid camping in El
Paredon. Built with Next.js (App Router) and Tailwind CSS.

See [CLAUDE.md](./CLAUDE.md) for the full project brief, design system,
and architecture notes.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the English site,
or [http://localhost:3000/es](http://localhost:3000/es) for Spanish.

## Deploy

Intended to deploy on [Vercel](https://vercel.com/new).
